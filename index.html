Project View

People's Meter

A people's meter is a TRP (Television Rating Point) slave data logger device that monitors individuals from 8 different age groups in a specific area and tracks which TV channels they watch most. It collects and processes viewer data, then sends it to the master TRP device, where the information is combined with the currently watched TV channel to analyze daily viewing patterns.

Tipsoi

Tipsoi is a cutting-edge biometric attendance and access control device that offers precise fingerprint scanning, RFID support, and real-time cloud integration. It has wireless GPRS, Wi-Fi, and LAN connectivity, ensuring seamless data transmission.

Thermal Printer

This thermal label printer supports printing via Bluetooth SPP and BLE communication protocols, as well as USB and Wi-Fi connectivity. It is compatible with mobile devices, offering dedicated applications for both Android and iOS. Android devices connect using SPP (Serial Port Profile), while iOS devices utilize BLE (Bluetooth Low Energy) for communication. In addition, the printer can be connected directly to computers via USB or accessed over a wireless network using Wi-Fi for flexible printing options across different devices.
